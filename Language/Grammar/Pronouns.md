# Pronouns

Only the plural pronouns are simple. The singular is [[gy]] *one* + the plural.

[[gy]] is optional. Without it the pronoun does not mark number: [[daz]] can mean *they* or *him*.
So a bare pronoun gets a person-only gloss: *daz* → `3`.

| | Plural | Singular |
|---|---|---|
| 1st person | [[bzy]] *we* | [[gybzy]] *I* — literally *one-we* |
| 2nd person | [[faz]] *you* | [[gyfaz]] *you* |
| 3rd person | [[daz]] *they* | [[gydaz]] *he, she*; [[kidaz]] *it* |

Zabzy 3 replaced the singular pronouns with borrowings: *co*, *śta*, *luź*.
