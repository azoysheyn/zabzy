# Transliteration

Each stage has its own Latin spelling.

| | Proto | Zabzy 1 | Zabzy 2 | Zabzy 3 |
|---|---|---|---|---|
| Long vowels | acute: *í é á ó ú* | plain | *ía éj áj ö ü* | plain |
| Short vowels | breve: *ĭ ĕ ă ŏ ŭ*, often unmarked | plain | | grave, low tone: *à ò ù* |
| ŋ | *nk*, *mk* | *ng* | *ñ* | *ń* (ɲ) |
| Postalveolars | *s*, *z* | *s*, *z* (ʂ, ʐ) | *s*, *z* | *ś*, *ź* |

In Zabzy 1, *ng* is one sound, ŋ. A real *n* followed by *g* is written *n'g*. The
apostrophe works the same way in the font: see [[Print]].

Proto *x* is a fricative, x ~ ç; Zabzy 1 *y* is ɨ.
