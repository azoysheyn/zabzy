# Zabzy Hand — рукописное письмо Zabzy 1

Шрифт для рукописного письма Zabzy 1. Пишешь латиницей — получаешь рукопись.
Собран 23 ноября 2026 из компонентов в Figma.

```
source/letters/*.svg + source/marks/*.svg → ./scripts/build.sh → dist/{otf,ttf,woff2}/ZabzyHand-Regular.*
```

## Как устроено письмо

| Что | Как пишется |
|---|---|
| согласная без гласной | одна буква: `z` |
| согласная + a или o | буква и знак гласной сверху: `za`, `zo` |
| u, i, y | отдельные буквы: `zu` = Z + U |
| a или o без согласной | знак на букве zero: `a`, `o`, `ama` |

Знак гласной стоит по центру над буквой. У G знак слева: справа у неё уходит вверх петля.
Буквы не соединяются.

## Интервалы и кернинг

Интервалы выровнены оптически, а не по рамкам компонентов.

1. Каждая буква получает поля 40 единиц слева и справа от своего контура.
2. Для каждой пары сборка ищет самое узкое место между буквами.
3. Кернинг сдвигает пару так, чтобы в самом узком месте осталось 38 единиц.
   После U — 60 единиц: U — один высокий штрих, и `ut`, `ur` при 38 выглядят тесно.
4. Кернинг не больше 200 единиц в любую сторону.
5. Кернинг считается по буквам, без знаков гласных: `daz` = `doz` = `dz`.
   Знак стоит сверху и интервал не меняет.
6. Знак гласной не подходит к соседу ближе 20 единиц. У G знак слева, у самой петли
   предыдущей G. Если знак мешает, раздвигается только вариант со знаком:
   `g ga` и `g a` шире, `g g` и `g zero` — как в таблице.

Правило выведено из ручного кернинга в Figma 23 ноября 2026. Образец был такой:
«mazmazang kifuranrug / ma daz kir kutnu zabzy», 12 px. После правок самое узкое
место в каждой паре — около 38 единиц, разброс — две ступени трекинга.

Восемь пар из этих правок записаны в `FIGMA_KERN`.
Пары `u→t` и `da→z` из правок вышли слишком тесными и идут по общему правилу.
Три пары подобраны на глаз после пробной печати, в `PAIR_GAP` (самое узкое место):

| Пара | Зазор |
|---|---|
| `u→t` | 85 |
| `n→r` | 70 |
| `z→ng` | 50 |

### Второй проход: таблица кернинга, 24 ноября 2026

Митя прошёл таблицу `specimen/kerning.html` и выставил 147 пар вручную. Это строки
M, F, BZ, PS, Z, S, R, G целиком и столбец M. Значения лежат в `source/kerning-manual.tsv`
и побеждают всё остальное.

Почти все правки раздвигают пары, в среднем на 50 единиц. Остальные пары получают
такой же сдвиг поверх правила выше:

```
сдвиг = LOOSEN + LOOSEN_LEFT[левая буква] + LOOSEN_RIGHT[правая буква]
```

- `LOOSEN` = 53 — общий сдвиг.
- После G сдвиг меньше (−38), после S, PS и T — больше (+12…+17).
- Перед I сдвиг больше (+17), перед BZ и T — меньше (−21 и −17).

Три набора чисел подобраны по 147 правкам методом наименьших квадратов. Проверка
с исключением по одной паре: медианная ошибка — 10 единиц, то есть один шаг в таблице.
88 % пар попадают в 30 единиц.

Защита знаков гласных работает и для ручных пар. Она раздвигает только варианты со знаком.

Параметры — в начале `scripts/build_font.py`: `SIDE`, `GAP`, `GAP_AFTER`, `MAX_KERN`,
`MIN_GAP`, `PAIR_GAP`, `FIGMA_KERN`, `LOOSEN`, `LOOSEN_LEFT`, `LOOSEN_RIGHT`.

## Как набирать

| Набрать | Получится |
|---|---|
| `b` или `bz` | BZ |
| `p` или `ps` | PS |
| `v` или `f` | F |
| `ng` | NG одной буквой |
| `n'g` | N, затем G — апостроф разделяет и сам не печатается |
| U+E000 | буква zero без знака |

Регистр не важен.

## Сборка

```
./scripts/build.sh
```

Первый запуск создаёт `.venv` и ставит `fonttools`, `svgpathtools`, `brotli`, `uharfbuzz`, `picosvg`.

Что делает сборка:

1. Собирает каждый знак из буквы и знака гласной по геометрии компонента → `build/composed/`.
2. Обводит штрихи: буквы нарисованы линией 3 px, а в шрифте нужны контуры → `build/svg/`.
3. Собирает шрифт конвейером скилла `svg-font-builder`: первый проход для замеров,
   второй — с кернингом по самому узкому месту.
4. Проверяет набор: `scripts/check_shaping.py`, 28 случаев.

Образец — `specimen/specimen.html` и `specimen/specimen.png`.

Таблица кернинга — `specimen/kerning.html`. Сборка делает её заново каждый раз.
В таблице все пары букв, кернинг каждой и откуда он взят. Пару можно сдвинуть
прямо на странице и скопировать список правок.
