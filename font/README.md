# Zabzy — письменность (шрифт Zabzy Bold)

Слоговое письмо: согласная, согласная + гласная (знак гласной сверху), гласная на
пустой основе. SVG лежат здесь же, имена — `B.svg`, `B + A.svg`, `+ A.svg`, `Default.svg`.

## Как набирать

| Набрать | Получится |
|---|---|
| `b` или `bz` | знак bz |
| `p` или `ps` | знак ps |
| `ng` | знак ng |
| `n'g` | n, затем g — апостроф разрывает и сам не печатается |
| `za`, `bzy`, `nga` … | слог одним знаком |
| `a i o u y` отдельно | гласная на основе |
| U+E000 | пустая основа (Default) без гласной |

Регистр не важен. Апостроф после любого знака — граница: `ak'a` → a, k, a.

## Сборка

```
.venv/bin/python scripts/build_font.py     # -> dist/{otf,ttf,woff2}/Zabzy-Bold.*
.venv/bin/python scripts/check_shaping.py  # проверки набора
```

`scripts/model.py` — состав письма и написания, `scripts/build_font.py` — метрики и
сборка (пайплайн из скилла `svg-font-builder`). Голые согласные нарисованы на холсте на
15 единиц ниже, чем слоги с гласной; сборка выравнивает их по общей базовой линии
(копии в `build/svg/`). Перекрывающиеся контуры сливаются при сборке.
